Detailed Description

Main program file.

Author
vkusnuiplov

This file is responsible for low-level MCU initialization, binding abstraction layers, and starting the infinite processing loop.

Architecture Overview

The project is organized in a multi-layered structure to isolate hardware:

  1. Application Layer (/application) High-level logic, FSM defines device states
  2. Drivers Layer (/actuators, /sensor) Hardware-independent peripheral drivers (LED, Buzzer, MQ7)
  3. BSP Layer (/bsp) Board Support Package. The file that links drivers and STM32 HAL
  4. HAL Low-level code generated by STM32CubeIDE

Convention Style Guide

_t [Type] : Structure type declarations _e [Enum] : Enumeration types for states and modes _h [Handle] : Specific instance of an object in memory _hw [Hardware] : Internal functions for direct hardware interaction

Execution Flow

  1. Reset & Clock Cleanup -> Core clock configuration
  2. Peripheral Init -> GPIO, ADC+DMA, TIM_PWM configuration
  3. Application Init -> Calling app_init(), binding BSP with drivers
  4. Infinite Loop -> Calling app_process() -> -> [ Sensors Update ] -> [ FSM Logic Check ] -> [ Actuators Refresh ]
