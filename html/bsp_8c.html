Detailed Description

Board Support Package (BSP) file for hardware abstraction.

Author
vkusnuiplov

This module acts as a hardware abstraction layer wrapper serving two main purposes:

  1. Binding logical drivers to physical MCU resources (Pins, Timers, ADC)
  2. Fully isolating business logic from STM32 HAL specific implementations
  • Logic Flow: Application -> Generic BSP API -> Hardware-Specific HAL -> Physical Pins Any schematic changes require modifications only in this file
