◆ ADC_TRIGGER_FREQ_HIGH

#define ADC_TRIGGER_FREQ_HIGH   (LL_ADC_TRIGGER_FREQ_HIGH)
Note
ADC trigger frequency mode must be set to low frequency when a duration is exceeded before ADC conversion start trigger event (between ADC enable and ADC conversion start trigger event or between two ADC conversion start trigger event). Duration value: Refer to device datasheet, parameter "tIdle". Trigger frequency mode set to high frequency.
