\doxysubsection{Detailed Description}
Board Support Package (BSP) file for hardware abstraction. 

\begin{DoxyAuthor}{Author}
vkusnuiplov
\end{DoxyAuthor}
This module acts as a hardware abstraction layer wrapper serving two main purposes:\+
\begin{DoxyEnumerate}
\item Binding logical drivers to physical MCU resources (Pins, Timers, ADC)
\item Fully isolating business logic from STM32 HAL specific implementations
\end{DoxyEnumerate}
\begin{DoxyItemize}
\item Logic Flow:\+ Application -\/\texorpdfstring{$>$}{>} Generic BSP API -\/\texorpdfstring{$>$}{>} Hardware-\/\+Specific HAL -\/\texorpdfstring{$>$}{>} Physical Pins Any schematic changes require modifications only in this file 
\end{DoxyItemize}
