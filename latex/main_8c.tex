This file is responsible for low-\/level MCU initialization, binding abstraction layers, and starting the infinite processing loop.\hypertarget{main_8c_Project}{}\doxysubsection{\texorpdfstring{Architecture Overview}{Architecture Overview}}\label{main_8c_Project}
The project is organized in a multi-\/layered structure to isolate hardware:\+


\begin{DoxyEnumerate}
\item Application Layer (/\+application) High-\/level logic, FSM defines device states
\item Drivers Layer (/\+actuators, /\+sensor) Hardware-\/independent peripheral drivers (LED, Buzzer, MQ7)
\item BSP Layer (/\+bsp) Board Support Package. The file that links drivers and STM32 HAL
\item HAL Low-\/level code generated by STM32\+Cube\+IDE
