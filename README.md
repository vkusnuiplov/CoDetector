## CO Detector
**Репозиторій коду проєкту датчика моніторингу рівня CO**

Проєкт реалізує систему моніторингу рівня чадного газу на базі аналогового сенсора **MQ-7** та мікроконтролера **STM32**. 

### Принцип роботи:
Пристрій виконує циклічний нагрів чутливого елемента, та аналіз напруги з резистивного подільника за допомогою АЦП, для подальшого розрахунку концентрації CO та сповіщення користувача.

### Індикація:
Користувацький інтерфейс включає двоколірну світлодіодну індикацію зелений світлодіод - прогрів та нормальна концентрація газу, червоний світлодіод - попередження та тривога.
Звукова сигналізація реалізована за допомогою бузера. Активується при досягненні високої концентрації газу.
